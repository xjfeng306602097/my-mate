# Presentation Artifact

Use for PPTX, slides, decks, layouts, notes, or presentation templates.

1. Establish audience, purpose, slide count, and visual constraints.
2. Build one clear message per slide with concise speaker notes where useful.
3. Preserve editable structure and avoid screenshots of text.
4. Return a complete slide specification to the Artifact Worker.
5. Verify rendered slides for clipping, overlap, contrast, and missing assets.
