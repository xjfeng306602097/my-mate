# Document Artifact

Use for document creation, translation, or revision where structure matters.

1. Identify the source, target language, output name, and whether formatting must be preserved.
2. Preserve headings, lists, tables, code blocks, links, and factual meaning.
3. Complete the full document rather than acknowledging future work.
4. For DOCX, return complete structured source content to the governed Artifact Worker; do not emit base64 or claim the file exists.
5. Verify completeness, language consistency, rendered preview, and download evidence before reporting success.
